## 1. canvases

The permanent top-level container for a user's thinking space. Never deleted.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Canvas identifier — passed everywhere as `canvas_id` |
| `user_id` | `UUID FK → auth.users` | Owner — used by RLS policy to restrict access |
| `title` | `TEXT NOT NULL` | Human-readable canvas name, shown in UI |
| `original_intent` | `TEXT NOT NULL` | The north star — WHY this canvas exists. Written once on creation, **never updated**. Immutability enforced by RLS policy. Injected into every agent serialization as Tier 0 anchor. |
| `canvas_version` | `INT NOT NULL DEFAULT 0` | **Context fingerprint** — a change-detector, NOT content. Bumped by a DB trigger on every `nodes` AND `edges` mutation (insert/update/delete), so re-parenting can't slip past. Powers the Impact Check + wake-time re-judge. See intervention-layer/04. |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp |

**RLS:** `user_id = auth.uid()` — users see only their own canvases.
**Constraint:** UPDATE policy blocks any change to `original_intent`.

## 2. sessions

An episodic thinking run within a canvas. A canvas can have many sessions over time.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Session identifier |
| `canvas_id` | `UUID FK → canvases` | Which canvas this session belongs to |
| `status` | `TEXT` | `active` or `closed` — only one active session per canvas at a time |
| `current_phase` | `TEXT` | `diverging` or `converging` — gates the judge's phase-bound agents (Expander vs Stress-Tester). v1 = one-way latch via `maybeAdvancePhase()`. |
| `node_sequence` | `UUID[]` | Ordered array of node IDs created **in this session only**. Updated atomically via `append_node_to_sequence()` RPC. Used by serializer to reconstruct the thinking trail. |
| `latest_seq` | `INT NOT NULL DEFAULT 0` | Monotonic version guard — the highest intervention `seq` allocated for this session. Bumped atomically by `allocate_session_seq()` RPC. A parked run whose `seq` falls behind is stale (intervention-layer/06). |
| `receptivity` | `NUMERIC(4,3) NOT NULL DEFAULT 0.500` | Decayed offer-response **timing** aggregate, `[0,1]`. Tunes show intensity + timer length. Fed by dismiss/ignore/process-now — **never** by content rejections (intervention-layer/05). |
| `receptivity_updated_at` | `TIMESTAMPTZ NOT NULL DEFAULT NOW()` | Last receptivity write — the anchor for the decay-toward-neutral calc. |
| `start_time` | `TIMESTAMPTZ` | When the session was started |
| `end_time` | `TIMESTAMPTZ nullable` | Set when session is closed via Session Complete flow. NULL = still active. |

**RLS:** Access via canvas ownership.

## 3. nodes

A single thought unit on the canvas. Created by the user (frontend writes directly to Supabase). Backend reads only — never inserts user nodes.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Node identifier |
| `canvas_id` | `UUID FK → canvases` | Which canvas — nodes are canvas-scoped, visible across ALL sessions |
| `session_id` | `UUID FK → sessions` | Which session created this node (for trail reconstruction) |
| `owner` | `TEXT` | `human` or `ai` — ghost nodes accepted into canvas are marked `ai` |
| `content` | `TEXT nullable` | Full text written by the user. NULL = empty node (has meaning — represents a thought not yet articulated). |
| `summary` | `TEXT nullable` | One-sentence directional summary generated by `gemini-2.5-flash` on node save. Begins with a direction marker word. Used in Tier 3/4 serialization and all cursor tools. |
| `direction_marker` | `TEXT nullable` | Extracted marker: `establishes`, `questions`, `contradicts`, or `explores`. Stored separately for fast filtering without parsing summary text. |
| `embedding` | `VECTOR(3072) nullable` | Semantic embedding from `gemini-embedding-exp-03-07`. Used by `semantic_promote` tool for cosine similarity search via pgvector. Generated once on node save. |
| `x` | `DOUBLE PRECISION nullable` | Canvas x-coordinate. **Frontend-owned** — written on node create/move, read on refetch to restore layout. Backend never touches. Nullable for pre-migration rows; new rows carry it. |
| `y` | `DOUBLE PRECISION nullable` | Canvas y-coordinate. Same ownership rules as `x`. |
| `width` | `DOUBLE PRECISION nullable` | Rendered node width. Same ownership rules as `x`. |
| `height` | `DOUBLE PRECISION nullable` | Rendered node height. Same ownership rules as `x`. |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp — used for ordering and window queries |

**RLS:** Access via canvas ownership.
**Note:** `embedding` index uses HNSW — requires pgvector ≥ 0.7.0 (production only; local Supabase dev skips this index).

## 4. edges

A directed connection between two nodes. Created by the user (frontend writes directly).

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Edge identifier |
| `canvas_id` | `UUID FK → canvases` | Canvas scope |
| `session_id` | `UUID FK → sessions` | Session that created this edge |
| `from_node_id` | `UUID FK → nodes` | Source node |
| `to_node_id` | `UUID FK → nodes` | Target node |
| `edge_type` | `TEXT NOT NULL` | `logical`, `doubt`, `question`, or `associative`. `question` edges trigger Outer Subconscious immediately. |
| `both_existing` | `BOOLEAN` | `true` when both `from_node_id` and `to_node_id` were already on the canvas before this edge was drawn. `true` triggers Articulator pipeline immediately (bypasses debounce). |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp |

**RLS:** Access via canvas ownership.

## 5. agent_threads

The persistent memory for each agent on a canvas. Per-canvas, not per-session — accumulates knowledge across all sessions. One row per `(canvas_id, agent_role)` pair.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Thread identifier — referenced by `rejection_insights.thread_id` |
| `canvas_id` | `UUID FK → canvases` | Canvas scope — threads span all sessions on this canvas |
| `agent_role` | `TEXT NOT NULL` | `expander`, `stress_tester`, `observer`, `outer_subconscious`, or `articulator` |
| `messages` | `JSONB[]` | Array of `ThreadMessage` objects (see `types/index.ts`). Appended atomically via `append_thread_message()` RPC — never read-modify-write. Contains the full conversation history: user canvas events + agent ghost pair responses + session boundary markers. |
| `active_rejection_insight_ids` | `UUID[]` | IDs of currently active `rejection_insights` rows. Loaded before every agent call to inject NEGATIVE CONSTRAINTS into the prompt. Updated by Rejection Insights Engine. |
| `updated_at` | `TIMESTAMPTZ` | Updated on every message append |

**Constraint:** `UNIQUE(canvas_id, agent_role)` — one thread per agent per canvas.
**RLS:** Access via canvas ownership.

## 6. attunement_state

A snapshot of the user's cognitive state at a point in time, produced by the Attunement Layer before every Orchestrator call.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Row identifier |
| `canvas_id` | `UUID FK → canvases` | Canvas scope |
| `session_id` | `UUID FK → sessions` | Session scope |
| `node_id` | `UUID FK → nodes nullable` | The trigger node that caused this attunement read |
| `cognitive_mode` | `TEXT NOT NULL` | `exploratory`, `transitional`, or `declarative` — read from language quality + node velocity. Drives question style selection. |
| `question_style` | `TEXT NOT NULL` | `opening`, `bridging`, or `closing` — passed to the routed agent to tune response style |
| `phase_shift_suggested` | `BOOLEAN` | `true` if Attunement Layer detects the user is ready to shift from diverging → converging. Passed to Orchestrator. |
| `confidence` | `NUMERIC(4,3) nullable` | Attunement confidence score 0.000–1.000 |
| `created_at` | `TIMESTAMPTZ` | Timestamp of this attunement read |

**RLS:** Access via canvas ownership.

## 7. rejection_insights

Structured negative constraints generated when a user rejects a ghost node pair
OR an Observer edge. Injected into subsequent agent prompts to prevent repeating
the same mistake. Two mutually exclusive categories per row, enforced by
`rejection_insights_category_xor`:
- **Content category** (Expander/Stress-Tester/Observer ghost rejections): `rejection_reason` set, `target_edge_id`/`connection_feedback` null
- **Connection category** (Observer edge rejections only): `target_edge_id`/`connection_feedback` set, `rejection_reason` null

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Insight identifier — stored in `agent_threads.active_rejection_insight_ids` |
| `canvas_id` | `UUID FK → canvases` | Canvas scope |
| `session_id` | `UUID FK → sessions nullable` | Session that produced this rejection |
| `thread_id` | `UUID FK → agent_threads nullable` | Which agent's thread produced the rejected ghost |
| `rejection_reason` | `TEXT nullable` | Content category only. User-selected reason: `too_abstract`, `too_technical`, or `skip_for_now` |
| `severity` | `TEXT NOT NULL` | `hard_block` (avoid completely), `approach_pivot` (keep idea, change approach), or `temporal_deferral` (pause for N turns) |
| `insight_points` | `JSONB` | Array of `InsightPoint` objects — the actual constraint text injected into prompts (e.g. "Avoid high-level analogies") |
| `turns_remaining` | `INT nullable` | For `temporal_deferral` only — counts down from N to 0. Decremented after each agent turn via `decrement_insight_turns()` RPC. NULL for non-temporal severities. |
| `active` | `BOOLEAN` | `true` = injected into prompts. Set to `false` when `turns_remaining` reaches 0 (temporal) or manually deactivated. Partial index on `(canvas_id) WHERE active = TRUE` for fast lookup. |
| `target_edge_id` | `UUID FK → observer_edges nullable` | Connection category only. The specific rejected edge this feedback is about |
| `connection_feedback` | `TEXT nullable` | Connection category only: `not_related`, `wrong_direction`, `too_indirect`, or `already_obvious` — see CORE-CONCEPTS.md → The Observer Structure |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp |

**RLS:** Access via canvas ownership.

## 10. subscriptions

Stripe subscription sync — one row per user. Drives tier enforcement in the Orchestrator (server-side only).

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Row identifier |
| `user_id` | `UUID FK → auth.users NOT NULL` | The subscribing user |
| `stripe_customer_id` | `TEXT nullable` | Stripe customer ID — set on first Stripe checkout |
| `stripe_subscription_id` | `TEXT nullable` | Stripe subscription ID — set when a paid plan is activated |
| `tier` | `TEXT NOT NULL` | `free`, `pro`, or `power` — the active tier. Default `free`. Determines which agents the Orchestrator can route to. |
| `status` | `TEXT NOT NULL` | `active`, `canceled`, or `past_due` — synced from Stripe webhook. Orchestrator checks `status = 'active'` before granting paid-tier agents. |
| `updated_at` | `TIMESTAMPTZ` | Last Stripe sync timestamp |

**Constraint:** `UNIQUE(user_id)` — one subscription row per user.
**RLS:** `user_id = auth.uid()`.

## 11. observer_structures

One row per Observer invocation. The Observer never writes a ghost pair into a
thread — it highlights existing canvas nodes (anchors) and proposes a
hierarchical DAG of new observation nodes. See CORE-CONCEPTS.md → The Observer
Structure for the user-facing model.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Structure identifier — referenced by `observer_edges.structure_id` |
| `canvas_id` | `UUID FK → canvases` | Canvas scope |
| `session_id` | `UUID FK → sessions nullable` | Session active when the Observer ran |
| `thread_id` | `UUID FK → agent_threads nullable` | The Observer's own thread |
| `anchor_node_ids` | `UUID[]` | Existing canvas nodes to highlight — hovering one reveals the structure |
| `nodes` | `JSONB` | Array of `ObservationNode` objects (`types/index.ts`): `{ghost_id, level, node_type, content}`. Written once at creation — never appended to, so no RPC needed. |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp |

**RLS:** Access via canvas ownership.

## 12. observer_edges

One row per accept/reject-able edge within an Observer structure — either an
anchor→observation edge or an observation→observation edge between levels.
Feedback is per-edge (the user flags an edge + a reason), but a rejection is a
re-think trigger, not a local delete: rejections batch (the user may flag
several improper edges before the structure vanishes), then the pending
structure is torn down and the Observer is re-invoked with all of them. See
CORE-CONCEPTS.md → The Observer Structure (steps 5-6).

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Edge identifier — referenced by `rejection_insights.target_edge_id` |
| `structure_id` | `UUID FK → observer_structures` | Which structure this edge belongs to |
| `from_id` | `UUID NOT NULL` | An anchor node id (real canvas node), or another observation node's `ghost_id` from the parent structure's `nodes` array |
| `to_id` | `UUID NOT NULL` | An observation node's `ghost_id` |
| `status` | `TEXT NOT NULL` | `pending`, `accepted`, or `rejected`. The node at `to_id` crosses into the canvas only once ALL its incoming edges are `accepted` (it is a synthesis of all of them). Any `rejected` edge batches into a re-think: the pending structure is torn down and the Observer re-invoked with every rejected edge. |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp |

**RLS:** Access via `observer_structures` → canvas ownership.

## 13. intervention_offers

The persisted handle for the decide→wait→generate handshake — the durable "in
flight" state every step of an intervention references by `id`/`seq`. **Ephemeral**:
it is operational state, not a permanent record. At a terminal status its
receptivity signal is folded into `sessions.receptivity` and then the row is purged
(session-close sweep + a TTL sweep for abandoned waits). The permanent "AI helped
here" record lives on `agent_threads` (`ghost_pair`) + `ai_contributions`, never
here. Full lifecycle: intervention-layer/05.

| Column | Type | Use |
|---|---|---|
| `id` | `UUID PK` | Offer id — pre-generated by the route so `step.waitForEvent` can match on it |
| `canvas_id` | `UUID FK → canvases` | Canvas scope |
| `session_id` | `UUID FK → sessions` | Session scope — single-flight is enforced per session |
| `agent_role` | `TEXT` | The judge's single-best route (`expander` \| `stress_tester` \| …) |
| `trigger_node_id` | `UUID FK → nodes` | The node whose activity invoked the judge |
| `anchor_node_ids` | `UUID[]` | The judge's `locus_node_ids` — where the move lands; the FE keys ghosts by `(anchor_node_id, seq)` |
| `seq` | `INT NOT NULL` | Per-session monotonic version, compared against `sessions.latest_seq` (intervention-layer/06) |
| `context_fingerprint` | `TEXT NOT NULL` | The `canvas_version` snapshot the offer was born from — change-detector for the Impact Check, NOT content |
| `directness` | `TEXT nullable` | `direct` \| `subtle` — set at show time by the show ruleset (intervention-layer/03) |
| `headline` | `TEXT nullable` | Backend-authored sidebar-card line — set at show time |
| `status` | `TEXT NOT NULL DEFAULT 'waiting'` | `waiting` → `shown` → `pulled`\|`dismissed`\|`superseded`\|`expired` |
| `created_at` | `TIMESTAMPTZ` | Creation timestamp — also the TTL anchor for the abandoned-wait sweep |
| `resolved_at` | `TIMESTAMPTZ nullable` | Set on any terminal status |

**RLS:** Access via canvas ownership.

## Foreign Key Hierarchy

```
auth.users
  └── canvases          (user_id)
        ├── sessions    (canvas_id)
        │     └── nodes (canvas_id + session_id)
        │     └── edges (canvas_id + session_id)
        ├── agent_threads         (canvas_id)
        ├── attunement_state      (canvas_id + session_id)
        ├── rejection_insights    (canvas_id + session_id + thread_id + target_edge_id)
        ├── ai_contributions      (canvas_id + session_id)
        ├── session_learnings     (canvas_id + session_id)
        ├── intervention_offers   (canvas_id + session_id + trigger_node_id)
        └── observer_structures   (canvas_id + session_id + thread_id)
              └── observer_edges  (structure_id)

auth.users
  └── subscriptions     (user_id)
```

All child tables cascade-delete on `canvases` delete (`ON DELETE CASCADE`).
`rejection_insights.target_edge_id` cascade-deletes on `observer_edges` delete.
